# Generated outputs

Use `<project>/<run>/parcel_stats`, `features`, `eda`, `ml_classification`, and
`sensitivity` for pipeline artifacts. Code-quality reports belong in `quality/`.
Generated files are ignored by Git. Previously tracked coverage and notebook
quality reports were retained locally under `quality/previous/`.

Use dedicated output directories: EDA and ML can reset their configured run
folders. Source imagery and reference data must live elsewhere.
