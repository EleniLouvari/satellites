ML classification workflow

How GeospatialClassificationPipeline goes from one row per parcel to a predicted class, probabilities and a confidence level for every parcel, in five restartable steps. Read from the code in src/ml_classification/. Defaults are those of ClassificationPipelineConfig.

flag = default input that controls the step only if … step is conditional

1 · Check

run_check(df) · writes 01_check/
1

Reset the project folder

By default every earlier output under project_dir is removed, so the five step folders always belong to one run.

project_dirreset_project_dir_on_run_check = Truefail_on_cleanup_error = False
2

Validate the table

One row per parcel. The ID column is cast to text (created from the index when missing) and must be unique. All feature columns and the target must exist. There must be at least two classes, and every class needs at least cv_folds labelled rows. Rows without a label are allowed: they are only predicted.

target_columnfeature_columnsid_column = "row_id"enforce_unique_ids = Truecv_folds = 5
3

Blank out feature outliers (IQR)

only if apply_iqr = True

For each numeric, non-boolean feature, values outside Q1 − k·IQR and Q3 + k·IQR are replaced with null. Nothing is deleted here; the nulls are handled in the next two steps.

apply_iqr = Falseiqr_lower_quantile = 0.25iqr_upper_quantile = 0.75iqr_multiplier = 1.5
4

Fill nulls from neighbouring parcels

only if fill_nulls = True

Null values of numeric features are interpolated spatially from other parcels with nearest, idw or kriging. Needs a GeoDataFrame. A method is mandatory when filling is on; idw needs the maximum distance and kriging the variogram maximum distance.

fill_nulls = Falsespatial_interpolation_method = Nonespatial_interpolation_max_distance_in_meters = Nonespatial_interpolation_variogram_lags = 15spatial_interpolation_variogram_max_distance_in_meters = None
5

Mark rows that must not be learned from

Two kinds of rows get excluded_from_training = True. They stay in the table and are still predicted at the end.

  • Rows with a null that was already in the input, when fill_nulls = False. Values blanked by the IQR filter do not count: they stay null and each model fills them from its training folds (median for numeric features).
  • Rows with is_outlier = True (the EDA flag), when the outlier option is on. The column must then exist.
fill_nulls = Falseexclude_outliers_from_training = False
6

Fix the active features and save

Features that are entirely null, or constant among the labelled rows, are dropped; the rest are the active features used by every later step. Numeric features are stored as float32, the others as categories. Saved: input_dataset.joblib, check_summary.json, feature_profile.csv, maps and the step report.

float_dtype = "float32"max_map_geometries = 20000
↓validated table, active features

2 · Prepare

run_prepare() · writes 02_prepare/
7

Keep the rows that can be learned from

Labelled rows that are not excluded. Class labels are encoded to integers and the mapping is saved as label_mapping.csv.

8

Hold out the test set

  • Random stratified (default): rows are drawn at random with the class shares preserved.
  • Spatial, by_row: a grid is laid over the parcels; rows are assigned so that every class is in both sets and both sets cover as many grid cells as possible.
  • Spatial, by_group: whole grid cells are held out, with the class shares kept approximately. Test parcels are then never neighbours of training parcels.
test_size = 0.2spatial_split = Falsespatial_split_method = "by_row"spatial_split_grid_size = 10random_state = 42
9

Build the cross-validation folds on the training set

Each validation fold targets 1 / cv_folds of the training rows and follows the same random or spatial logic as the split.

  • disjoint: every training row is validated exactly once.
  • overlapping: each fold is drawn independently, so rows can repeat. A separate disjoint set of folds is then also saved for the out-of-fold probabilities of step 12.
cv_folds = 5cv_validation_method = "disjoint"

Saved: train_dataset.joblib, test_dataset.joblib, labeled_dataset.joblib, prepare_summary.json with the fold indices.

↓train set, test set, folds

3 · Train

run_train() · writes 03_train/ · training set only
10

Build one pipeline per candidate model

selected_models = None means every available model: logistic_regression, linear_sgd_classifier, support_vector_machine, random_forest, extra_trees, gradient_boosting, decision_tree, knn, neural_network, bagging, bayesian. Added when possible: hist_gradient_boosting (no categorical features), xgboost and lightgbm (if installed), tensorflow_neural_network and keras_lstm (if TensorFlow is installed).

Each pipeline does its own preprocessing, fitted on training folds only:

  • Numeric features: median imputation, plus standard scaling for the scale-sensitive models.
  • Categorical features: most-frequent imputation, then one-hot encoding with rare levels grouped.
  • Optional resampling of the minority classes placed after preprocessing: random_oversample or smote.
selected_models = Nonelabel_balancing_method = "none"smote_k_neighbors = 5rare_category_min_frequency = 10

keras_lstm reads the dated feature columns as a time sequence: lstm_temporal_statistics ("median",) · lstm_temporal_frequency "monthly" · lstm_require_complete_timesteps True · lstm_min_timesteps 6 · lstm_class_balancing_method "balanced_class_weight".

11

Search the hyperparameters

Per model, a successive-halving random search (factor 2) over its grid in tune_params, scored with the primary metric on the folds of step 9. At most max_search_candidates combinations are tried. The best setting is refitted on the whole training set. A model that fails is recorded and the others continue.

max_search_candidates = 40scoring_primary = "f1_macro"tune_paramsn_jobs = -1random_state = 42
12

Save out-of-fold probabilities

only if rank_confidence_enabled or optimize_class_probabilities

With the winning setting, each training row is predicted by a model that did not see it (disjoint folds). These probabilities are the honest evidence later used for class reliability and probability optimisation.

13

Rank the models

score_minus_std ranks by mean fold score minus its standard deviation, which favours models that are stable across folds. mean_score ranks by the mean only. On a rerun, models that already have complete artifacts are reused unless retraining is forced.

cv_ranking_method = "score_minus_std"force_retrain_models = False

Saved: one folder per model, training_summary.csv, best_cv_fold_scores.csv, training_failed_models.csv, model_specs.json.

↓tuned models, CV ranking, OOF probabilities

4 · Evaluate

run_evaluate() · writes 04_evaluate/
14

Score every model on the train and test sets

Accuracy, balanced accuracy, macro and weighted F1, weighted precision and recall, weighted ROC AUC, and a confusion matrix per model. The test set is used for reporting only.

scoring_primary = "f1_macro"scoring_secondary = ("balanced_accuracy", "f1_weighted", "accuracy")
15

Explain the top models

Feature importances (or coefficient magnitudes) for the best models, and SHAP summaries on a sample of training rows when enabled.

interpretability_top_models = 3feature_importance_top_n = 15interpretability_include_shap = Falseshap_sample_size = 500
16

Choose the final strategy from the cross-validation ranking

  • soft_voting: the models that output probabilities, in CV rank order and limited to top_voting_models, vote by averaging their class probabilities.
  • single_model: the best-ranked model alone. Also the fallback when fewer than two models are available.

The choice never looks at the test set.

selection_type = "soft_voting"top_voting_models = None
17

Tune class probability multipliers

only if optimize_class_probabilities = True

Starting from 1.0 for each class, a coordinate search tries each grid value per class on the averaged out-of-fold probabilities and keeps a change only if macro F1 improves and accuracy does not fall by more than the allowed drop. The multipliers rescale the probabilities, which are then renormalised.

optimize_class_probabilities = Falseprobability_multiplier_grid = (0.8, 1.0, 1.2, 1.5, 2.0)probability_optimization_iterations = 2probability_optimization_max_accuracy_drop = 0.02
18

Freeze the confidence contract

Two things are fixed here and stored in selection_summary.json, so step 5 cannot drift with later setting changes:

  • The rank-confidence thresholds of step 21, and the two probability limits used when too few models vote.
  • Class reliability: from the out-of-fold soft-voting predictions, the precision of each predicted class. Fewer than the minimum predictions gives an invalid LOW; otherwise precision ≥ 0.80 is HIGH, ≥ 0.60 is MEDIUM, below is LOW.
rank_confidence_enabled = Trueclass_reliability_enabled = Trueclass_reliability_minimum_oof_support = 100class_reliability_high_min_precision = 0.80class_reliability_medium_min_precision = 0.60

Saved: metric tables with and without voting, ranking and confidence tables, selection_summary.json, the step report and the final dashboard.

↓frozen strategy and confidence contract

5 · Predict

run_predict() · writes 05_predict/ · every row
19

Refit on all labelled rows and predict every parcel

Each selected model is rebuilt with its best hyperparameters and fitted on all rows that can be learned from (training and test together). It then outputs class probabilities for every row, including unlabelled and excluded ones.

20

Decide the class

Member probabilities are averaged, the multipliers of step 17 are applied, and the class with the highest probability wins.

prediction_column = Noneprediction_filled_column = Noneprobability_prefix = "probability"prediction_confidence_column = "prediction_max_probability"

Columns: <target>_prediction, predicted_class, probability_<class>, prediction_max_probability, and <target>_filled, which keeps the declared label and uses the prediction only where the label is missing.

21

Rate the confidence of each prediction by rank agreement

Each voting model ranks the classes for the parcel. A rank becomes a Borda score from 100 (first) to 0 (last), and the scores are averaged over the models. The rank range is the gap between the best and worst rank the models gave to the predicted class.

LevelMean Borda of predicted classRank range
HIGH≥ 90≤ 2
MEDIUM≥ 75≤ 4
LOWeverything else

A parcel is also LOW when the Borda winner is tied or differs from the voted class.

Fewer voting models than the minimum (for example a single-model run): rank agreement cannot be measured, so the level comes from the mean probability of the predicted class instead: HIGH from 0.80, MEDIUM from 0.60, otherwise LOW. These predictions stay valid; their reasons start with probability_fallback_ and prediction_confidence_source is probability_fallback.

prediction_needs_review is True for LOW or invalid confidence. If rank confidence is disabled, it is True when the highest probability is below the threshold.

rank_confidence_minimum_models = 3rank_confidence_high_min_borda = 90.0rank_confidence_high_max_range = 2.0rank_confidence_medium_min_borda = 75.0rank_confidence_medium_max_range = 4.0prediction_confidence_threshold = 0.60prediction_high_confidence_threshold = 0.80
22

Assign the inspection priority

only if inspection_scoring_enabled = True

Confidence, class reliability, the declared label, data reliability, geometry complexity and optionally the EDA outlier flag are combined into a seven-level priority and a check type. The inspection priority workflow page describes this step. It is skipped with a warning when the data-reliability or geometry column is missing.

inspection_scoring_enabled = True
23

Save the results

final_predictions.joblib (all columns), final_predictions_preview.csv, member_probabilities.joblib, predict_summary.json, the step report, the final dashboard and report_index.html. recalculate_prediction_quality() repeats steps 21 and 22 from the saved probabilities without refitting.

open_html_report = Truemax_features_per_plot = 20max_distribution_features = 9

Things to know before choosing values

  • apply_iqr=True keeps parcels in training: blanked values are imputed by the models. Only nulls already in the input exclude a parcel when fill_nulls=False.
  • With fewer than 3 voting models the confidence comes from the predicted-class probability, which is less informative than rank agreement. Prefer at least 3 models in the vote.
  • The test set never selects models, strategy or thresholds. Step 5 then refits on training and test rows together, so the test metrics describe models trained on less data than the final ones.
  • Rank thresholds and class reliability are frozen in step 4. Changing them afterwards has no effect until step 4 is run again. The inspection_* settings are read in step 5 and can be re-applied with recalculate_prediction_quality().
  • Several models already use balanced class weights by themselves. label_balancing_method adds resampling on top of that.
  • run_check deletes earlier outputs by default. To continue a stopped run, call the next run_* step instead of starting again from the check.
